Detailed Description

template<UartPort Port>
class fdo2::FDO2< Port >

Driver for one FDO2-G2 or FDO2 on a platform port.

Lifecycle: construct with the configuration (no I/O), then BeginInitialize() and Poll() or EnsureInitialized(), use, optionally Deinitialize(). Every call that touches the module returns Error::NotInitialized until start-up has succeeded.

Optional port hooks, found at compile time:

  • void DelayUs(uint32_t us) noexcept: the blocking calls and PowerCycle(); without it the first blocking call is a compile error.
  • uint32_t NowUs() noexcept: Poll() measures its own time; without it only Poll(elapsed_us) exists.
  • bool SetBaudRate(uint32_t) noexcept: #BAUD and Resync(); without it SetBaudRate() returns Unsupported.
  • bool GpioSet(CtrlPin, GpioSignal) noexcept: CtrlPin::Power at start-up, in Deinitialize() and in PowerCycle(); without it the application powers the module and PowerCycle() returns Unsupported.
  • void Log(LogLevel, const char*) noexcept: one line per lifecycle event or failure; without it nothing is logged.

A hook declared with the wrong signature is a compile error.

Start the module without waiting: validate the Config, bring the UART up, power the module through GpioSet(CtrlPin::Power) when the port has it, and enter PoweringUp.

◆ Deinitialize()

template<UartPort Port>
Result< void > fdo2::FDO2< Port >::Deinitialize ( )
noexcept

Drop the operation in flight, leave the broadcast alone, set the power pin INACTIVE (when the port has it) and mark the driver uninitialised. A failed pin write is reported as Bus.

The supply is never cut while a flash write may be in progress (datasheet 4.3, WARNING: a power loss during a flash cycle can corrupt the memory): the call returns Busy, changes nothing, and succeeds once the echo has arrived or the write's allowance has elapsed (FlashWritePending() says which; the time passes with Poll()). On a port without NowUs() the time moves only through Poll(elapsed_us): a caller that never polls stays Busy.

Returns
Ok, Busy (a flash write is pending) or Bus.
