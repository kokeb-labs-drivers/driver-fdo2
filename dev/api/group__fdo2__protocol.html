constexpr std::size_t fdo2::EncodeCommand ( Command  command,
std::span< const int32_t >  args,
std::span< char >  out 
)
constexprnoexcept

Encode a command line: #HEAD, each argument as plain decimal with one space before it, and one carriage return (never a LF: datasheet 4.1 allows CR or CR LF, the driver sends CR).

The arguments are range-checked first (R 0 to 63, N 1 to 64, R + N at most 64, a baud rate from the table, #BCST 0 or 100 to 10000, #SETM 0 to 4, #CRCE 0 or 1, #CAHI not 0, and the count of arguments).

Parameters
commandThe command.
argsThe arguments; for Wrum R, N, Y1 ... YN.
outThe buffer; at least kMaxCommandLength bytes fits every command.
Returns
The length written, including the CR; 0 when an argument is invalid or out is short.

◆ ParseLine()

constexpr ParsedLine fdo2::ParseLine ( std::span< const char >  line,
const ParseOptions &  options 
)
constexprnoexcept

Parse one reply line (without its CR) under the grammar of datasheet 4.

(1) The CRC suffix : C (when present or required) is checked over every character before the colon. (2) The header is # and four letters A to Z, then the end or a space. (3) Values are separated by exactly one space (strict_spacing), each is 0 or an optional minus and a digit 1 to 9 and digits, in range for its field (S unsigned 32 bit, #IDNR unsigned 64 bit, the rest signed 32 bit). #ERRO is exactly #ERRO E with E negative. The token count is checked by the caller against the command's reply (ExpectedCount()). No allocation, no strtol, no locale.

Parameters
lineThe line, without CR.
optionsThe CRC and spacing rules.
Returns
The parsed line; check status, then known, erro, command.
