enum class fdo2::CrcMode : uint8_t

Whether replies carry the CRC-16 suffix (datasheet 4.2).

Enumerator
Auto 

Learn from the first #VERS reply: a suffix means CRC is on.

Off 

Never expect a suffix: a reply with one is InvalidReply.

Required 

Every reply must carry a valid suffix (except #ERRO with erro_without_crc).

◆ Error

enum class fdo2::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. [[nodiscard]] on the type: a function that returns a bare Error cannot have it ignored either (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded, or Deinitialize() ran since.

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

A port hook returned false.

Timeout 

No complete reply within the deadline (datasheet 4.1, 4.3).

DeviceIdMismatch 

#VERS is not an FDO2 with an oxygen sensor: wrong device or wiring.

Crc 

The CRC-16 of a reply did not match (datasheet 4.2).

Busy 

An operation is pending, draining or the module streams.

DeviceFault 

#ERRO with a code the datasheet calls potentially fatal (4.4).

Unsupported 

The hook, firmware revision or family does not offer this call.

DeviceError 

#ERRO -1, -21, -22 or -23: the module could not do it.

InvalidReply 

A line the protocol grammar refuses (bytes, header, tokens, number).

EchoMismatch 

The header or an echoed value differs from what was sent (4.2).

SensorFault 

The status word was rejected by the StatusPolicy (4.3, #MOXY).

OutOfRange 

A decoded value is outside the plausibility window of the Config.

CalibrationRejected 

#ERRO -60: the calibration is outside the expected range.

NotPermitted 

A flash-writing call without consent, or over the write budget.

StateUnknown 

A flash write or baud change ended without a confirmed echo.

BroadcastActive 

The module streams #MRAW lines and the call needs it silent.

NotReady 

Warming up: a calibration needs a settled sensor (datasheet 2).

Fails when a baud rate is not one of the eleven, a timeout is out of its bound, retries is above 3, an enumeration holds a value that is not an enumerator, the plausibility windows are not ordered, pressure_reference_ubar is neither 0 nor inside the pressure window, or max_flash_writes is outside 1 to 64, cal_window_pct is outside 1 to 100 or cal_window_min_mhpa is outside 1000 to 50000.

Returns

◆ VolumePercentMilli()

constexpr Result< int32_t > fdo2::VolumePercentMilli ( int32_t  o2_mhpa,
int32_t  pressure_ubar 
)
constexprnoexcept

The oxygen content in volume percent of the gas at the membrane (datasheet 2, p. 6): 100 x pO2 / p, in 10^-3 percent, rounded half up.

The factor 1000 of the two units cancels (o2_mhpa and pressure_ubar are both thousandths).

Parameters
o2_mhpaThe partial pressure, 10^-3 hPa.
pressure_ubarThe total pressure at the membrane, microbar (equal to 10^-3 hPa).
Returns
10^-3 percent (20351 is 20.351 percent); InvalidArgument for a pressure of 0 or below, OutOfRange when the result does not fit 32 bits. Never a silent 0.
