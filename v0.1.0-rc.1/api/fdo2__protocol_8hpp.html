Detailed Description

The FDO2 line protocol as pure functions: CRC-16, command encoders, the line assembler and the strict reply parser. No port, no state outside the objects, no allocation.

Datasheet section 4 (G2 data sheet, printed pages 10 to 17). A command is #HEAD, values separated by single spaces, and a carriage return; the module answers with the command echoed and the requested values, ended by one carriage return, with : C (the CRC-16/MODBUS in decimal) before it when #CRCE 1 is active. An error is #ERRO E with a negative E.

Because the layer is pure (bytes in, a struct out), an interrupt handler, a DMA completion or an RTOS task can decode what it received with the same checks the driver applies, and the fuzz target drives the parser directly.
