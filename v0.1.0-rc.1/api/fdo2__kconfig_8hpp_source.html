fdo2::Family::Fdo2
@ Fdo2
FDO2, the legacy module (firmware 3.28 to 3.55); no #SETM in its data sheet.
fdo2::CrcMode::Auto
@ Auto
Learn from the first #VERS reply: a suffix means CRC is on.
fdo2::CrcMode::Required
@ Required
Every reply must carry a valid suffix (except #ERRO with erro_without_crc).
fdo2::CrcMode::Off
@ Off
Never expect a suffix: a reply with one is InvalidReply.
fdo2::BroadcastPolicy::Disable
@ Disable
Send #BCST 0 (a flash write: needs allow_persistent_writes).
fdo2::BroadcastPolicy::Refuse
@ Refuse
Fail with BroadcastActive; the driver stays uninitialised.
fdo2::BroadcastPolicy::Stream
@ Stream
Go to the Streaming state and decode the frames.
fdo2::StatusPolicy::Documented
@ Documented
Only fatal and undefined bits are SensorFault; bits 7, 9, 10 are Degraded.
