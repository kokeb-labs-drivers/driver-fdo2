Detailed Description

Collects the bytes of a reply into lines, one byte at a time (datasheet 4.1: one CR ends a reply).

A byte outside 0x20 to 0x7E other than CR (a LF at the start of a line is dropped when ignore_lf), or 800 characters without a CR, makes PushByte() return Bad once; the rest of that line is discarded up to the next CR (resynchronisation) and counted. A line is never delivered without its CR; an empty line (CR alone) is ignored.
