Detailed Description

Public types of the FDO2 driver: errors, Result<T>, the status word, measurements, configuration, firmware capabilities and the pure conversions.

Copyright
Copyright (c) 2026 The driver-fdo2 authors. SPDX-License-Identifier: MIT

Everything here is plain data and constexpr functions with no platform dependency, so handlers, tests and tools can include it without the driver class. Values keep the units the module reports (datasheet section 4.3): 10^-3 hPa, 10^-3 degC, millidegrees, microvolts, microbar and 10^-3 RH, as integers; the unit is part of each name.
