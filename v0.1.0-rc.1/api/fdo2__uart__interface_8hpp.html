Detailed Description

The UART port of the FDO2 driver: the CRTP base, its pin enums, the UartPort concept and the line requirements.

Copyright (c) 2026 The driver-fdo2 authors. SPDX-License-Identifier: MIT

The driver never calls an SDK. It calls hooks on a class you derive from fdo2::UartInterface<Self>:

  • bool EnsureInitialized() noexcept (required): UART up at Config::baud (19200 after every power-up), 8N1, no flow control; true at once afterwards.
  • bool Write(const uint8_t* data, std::size_t len) noexcept (required): send all len bytes (may block until queued); false on an error. One command line per call.
  • std::size_t Read(uint8_t* data, std::size_t max, uint32_t timeout_ms) noexcept (required): return the bytes already received, 0 to max, waiting at most timeout_ms for the first byte; 0 must not block; never more than max.
  • bool FlushInput() noexcept (required): drop every received byte not yet returned by Read().
  • void DelayUs(uint32_t us) noexcept (for the blocking calls): wait at least us; a compile error at the first blocking call otherwise.
  • uint32_t NowUs() noexcept (optional): free-running monotonic microsecond counter, wrap-safe; with it Poll() measures its own time, without it Poll(elapsed_us) exists.
  • bool SetBaudRate(uint32_t baud) noexcept (optional): reconfigure the UART; without it SetBaudRate() returns Unsupported.
  • bool GpioSet(CtrlPin, GpioSignal) noexcept (optional): CtrlPin::Power: ACTIVE powers the module (an external load switch).
  • void Log(LogLevel, const char*) noexcept (optional): plain text, never a format.

19200 baud, 8 data bits, no parity, 1 stop bit, no handshake after every power-up (datasheet section 4). The port moves raw bytes; the driver builds, frames, checks and times everything. Read() is not an all-or-nothing read: the reply length is unknown, so it returns the count received. A port whose SDK returns only a status polls its FIFO level first.
