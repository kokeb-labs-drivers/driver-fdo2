# FDO2 Driver API reference {#mainpage}

The classes, types and registers of the FDO2 driver, generated from the headers in `inc/`.

Start with fdo2::FDO2, the driver, and fdo2::UartInterface, the base of the port you write. Errors are
fdo2::Error inside fdo2::Result; the configuration is fdo2::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">FDO2 Driver
documentation</a>.
